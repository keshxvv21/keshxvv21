## 🚀 Featured Projects

### 🛰️ [APOGEE](https://github.com/keshxvv21/APOGEE)

A real-time **3D tactical orbital tracking interface** that visualizes live crewed stations and orbital assets.

Uses **D3.js** for interactive 3D visuals and **SGP4 propagation** to calculate satellite positions and forecast orbital trajectories.

**D3.js · SGP4 · JavaScript**

---

### 📺 [Neo-YouTube-Downloader](https://github.com/keshxvv21/Neo-Youtube-Downloader)

A desktop YouTube downloader with a **neo-brutalist UI** featuring thick borders and hard shadows.

Fetches metadata before download, supports video + audio, video-only, and MP3 formats, detects resolutions dynamically, handles playlists, shows live download speed/ETA, and maintains a download history.

**Python · yt-dlp · Tkinter · FFmpeg**

---

### 🧠 [DocuMind — Local RAG Study Assistant](https://github.com/keshxvv21/DocuMind)

An **offline document Q&A tool** that allows users to upload PDF or TXT files and get answers from their own material using local LLMs, with semantic search and document processing under the hood.

**Python · Flask · FAISS · Hugging Face · Ollama · TinyLlama**
